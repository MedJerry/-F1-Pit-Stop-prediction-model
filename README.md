# -F1-Pit-Stop-prediction-model
Developed an F1 Pit Stop prediction model to classify whether a driver will pit on the next lap using real F1 race telemetry data. Engineered features like Tyre Life squared, Lap Time × Tyre Life, and Degradation per lap. Trained a LightGBM classifier with Optuna hyperparameter tuning
GOT ROC-AUC SCORE :- 0.94778 -> 94% ACCURACY
